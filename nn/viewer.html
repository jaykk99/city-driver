City Driver NN — taxi tip predictor

Pure-stdlib MLP. Predicts whether a completed taxi ride earns a tip, from the ride's own stats.
PREDICTION ONLY. This network never changes game state and never pays anything — the game itself (js/taxi.js) decides the tip. The tip rule is deterministic (on time + not wrecked = tip), so near-100% test accuracy is expected and is not a discovery: the model is a learned surrogate of tipFor. The fares are simulated by driving the real taxi state machine with seeded RNGs — no real player drove them.
